# MOD Convolution Loader

> **Archived (November 2026).** This code is no longer developed. MOD Cabinet Loader and MOD Convolution Loader
> continue as MOD plugins on a new engine, closed source, and stay free in the MOD Plugin Store.
> The code in this repository remains available under its ISC licence (see `LICENSE`).

Based on DISTRHO OneKnob Convolution Reverb, specially tweaked for MOD Audio.

A mono cabinet-focused and a stereo reverb-focused loader are available.
